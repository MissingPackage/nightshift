Continue the autonomous research loop for this project. Follow the loop-iteration skill.

Standing rules:
- **The objective is a contribution**, stated in the map head line as the question and how much
  of the answer we have. The first line of every digest says whether this iteration moved that,
  not whether the experiment ran.
- **Pre-register before spending.** Where the project keeps `research/predictions.md`, write the
  prediction before any `--execute`; dry-run and show the cost estimate before real API spend.
  Spend beyond the cap in the project CLAUDE.md is one of the four kinds: ask, one line.
- **Cheap kill first.** The smallest run that can kill the hypothesis; the full tranche only for a
  hypothesis that survived it.
- **Grade honestly.** Negative and null results go into `.harness/tried.md` with the same care.

Each iteration: re-anchor from the map (or `research/AGENDA.md` where that is the map) → biggest
gap in the contribution → the experiment that can kill the current hypothesis → grade → redraw
the map, append to tried.md → three-line digest → schedule or stop by design when everything
left is one of the four kinds.
